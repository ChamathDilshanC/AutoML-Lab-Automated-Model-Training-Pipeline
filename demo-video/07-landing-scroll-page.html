How it works

From a raw CSV to an approved model.

Three steps, no code. Every step is recorded so you can reproduce it.

01

Upload and validate

Drag in a tabular CSV. It is stored privately and checked straight away: every column's type, missing values and distinct values, with warnings.

  • Schema
  • Missing values
  • Warnings
02

Train and compare

Pick a target and a metric. A worker tunes each allowlisted algorithm with cross-validation on the training rows, then ranks them on a held-out test set.

  • Cross-validation
  • Held-out test
  • Leaderboard
03

Approve and predict

The best model is registered as a new version. Approve it, then get predictions from its page or over the API.

  • Versioned
  • Approval
  • Prediction API

Regression
  • Linear Regression

No test-set leakage

The target is never a feature. Imputers, encoders and scalers are fitted on training rows only, inside one scikit-learn pipeline.

Reproducible

Every experiment records its random seed, split strategy and library versions.

  • seed 42
  • stratified split

Schema-checked predictions

Inputs are checked against the model's schema; missing, extra or invalid fields are rejected. Each answer names the model version and a request ID.

A versioned, immutable registry

The winning pipeline is saved with its feature schema, metrics and training configuration. A version never changes: a new run makes a new version.

Version 1 → Pending approval → Approved

Private and yours

Files go straight to a private S3 bucket through a short-lived presigned URL. Sign in with Google; every dataset, experiment and model is checked against its owner.

Security first

Nothing serves until you approve it.

A registered model starts as Pending approval. Only approved models answer prediction requests.

  • Approval gatePredictions stay off until you click Approve and confirm.
  • Permanent revocationRevoking stops predictions immediately. A new experiment makes a new version.
  • Trusted artifacts onlyModel files are loaded only if this system produced them, after a SHA-256 check.
  • No user code, everAlgorithm names are looked up in an allowlist, never imported from your data or settings.
